rc-screening Privacy Policy

Last updated: October 17, 2026

Who uses this app

rc-screening is a personal tool used only by its developer, with the developer's own Google account. It is not offered to other users.

Google user data the app accesses

  • Read Gmail (gmail.readonly): the app searches the developer's own mailbox for real-estate listing notification emails, and reads their content and attachments.
  • Send Gmail (gmail.send): the app sends a summary email to the developer's own address only.

How the data is used

The data is used only to screen the listed properties against the developer's own criteria and to report the result to the developer. It is not used for advertising, profiling, or training AI or machine-learning models.

How the data is stored

The app keeps a small processing record (message ID, sender, subject, and the listings that passed screening) in the developer's own Google Cloud project, so the same email is not processed twice. Authorization credentials are kept in Google Cloud Secret Manager in the same project. Listing attachments may also be downloaded to the developer's own computer for the same screening purpose.

Sharing

Google user data is not sold, and is not shared with any third party for their own purposes. The developer may analyze the listing data with AI assistant tools that the developer uses for this screening work; such use is solely on the developer's behalf.

Limited Use

rc-screening's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from Google Account > Third-party connections. The processing record can be deleted by the developer from the Google Cloud project.

Changes and contact

This policy is updated on this page when the app changes. Questions can be sent to the developer via the GitHub account JKORAP.
